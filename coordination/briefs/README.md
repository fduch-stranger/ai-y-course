## Layers

- **L1 — raw history:** the Codex task is the current source. Automatic export to a separate private archive is not configured. Never put raw histories in this public repository.
- **L2 — task brief:** the files in this directory. Update the current task's brief before handoff or completion.
- **L3 — curated project memory:** `PROJECT_MAP.md`, `DECISIONS.md`, `MISTAKES.md`, `BACKLOG.md`, `WORKSTREAMS.md`, and the daily log.

For a new Codex task, use `CODEX_THREAD_ID` as its stable identifier and add one row here. Keep only project-relevant facts; exclude credentials, personal data, full prompts, and raw transcripts.
